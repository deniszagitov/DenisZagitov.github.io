# Career brand assets

Used only to identify employers in the career section. The marks are rendered as single-colour CSS masks; no external asset requests are made by visitors.

- `adviva.svg`: wordmark extracted from the official header at https://adviva.com/ on 2026-11-08. Original path geometry retained; site-specific classes removed.
- `sber.svg`: emblem from https://commons.wikimedia.org/wiki/File:Sberbank_Logo_2020.svg (author: Sberbank; source listed as https://www.sber.ru/bank). The SVG viewport is limited to the original 50 × 50 emblem; the accompanying name is localised as Сбер / Sber. Commons identifies the source as a public-domain text logo and notes trademark restrictions.
- `gazprom-neft-ru.svg`, `gazprom-neft-en.svg`: vector wordmarks from https://logo-teka.com/gazprom-neft/. The company’s identity was cross-checked with the logo sourced from its official site at https://commons.wikimedia.org/wiki/File:Gazprom_Neft_-_logo.png. Original vector geometry retained.
- `shell.svg`: monochrome Pecten from https://github.com/simple-icons/simple-icons/blob/develop/icons/shell.svg. Simple Icons artwork is distributed under CC0; Shell identity reference: https://www.shell.com/who-we-are/our-history/our-brand-history.html.

Company names and marks remain the property of their respective owners. The strip describes career experience.
